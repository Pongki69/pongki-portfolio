Place exactly one image in this folder, then double-click replace-photo.bat in the portfolio folder.

Supported formats: JPG, JPEG, PNG, BMP, and GIF. The image will be center-cropped to a square and resized with high-quality filtering to the 880px PNG used by the website. The helper will commit and push only the updated portfolio photo.

Remove the previous image before adding a new one. Temporary files in this folder are excluded from Git.
